# 모바일 기본 화면 및 지도 연동 작업 기록

2026-11-03

## 범위

기존 준비 중 페이지를 모바일 우선 메뉴 탐색 UI로 교체.
배포는 기존 GitHub Pages를 유지하고 Android 프로젝트와 별도 경로에서 작업.
지도용 Client ID는 사용자 제공 대기. Secret은 필요하지 않음.

## 검증

- `npm test`: 5개 통과. 구면 거리(미터), 반경·예산·메뉴·업종 교집합,
  모서리 역전 시 사각형 경계, 미등록 가격 처리, 추천 중복 방지·원본 보존.
- `node --check app.js`: 통과.
- 로컬 브라우저 390px: 가로 넘침 없음. 1만원 이하 적용 시 3개,
  한식 추가 시 1개, 메뉴 저장 및 저장 목록, 상세 팝업과 리뷰 안내 확인.
- 예시 데이터 토글 off: 빈 상태와 추천 버튼 비활성 확인.
- 320px에서 발견한 카테고리 행 4px 넘침 보정.

## 남은 범위

- 네이버 실제 지도 인증/타일/영역 드래그: Client ID 수령 후 검증 필요.
- 실제 iPhone Safari / Android Chrome 터치·GPS 권한: 미검증.
- 실제 식당·메뉴, Google OAuth, 부서 권한, 리뷰 DB: 미구현.
- 이 기록은 브라우저 화면 크기 검증을 실제 모바일 기기 검증으로 간주하지 않음.

## 추가 브라우저 검증

- 320px 보정 후 document scrollWidth=320 / innerWidth=320 확인.
- 메뉴명 검색(우동): 1개. 없는 메뉴 검색: 빈 상태. 초기화 후 추천: 3개 확인.
- 새로고침 후 저장한 메뉴 유지 확인.
- 1280px에서 지도/목록 2열 배치 확인.
- 현 단계는 Client ID가 비어 있어 실제 지도 연동 완료가 아닌 연결 코드 준비 상태.


## 네이버 지도 실제 연결 및 검증 (2026-11-03)

- 사용자 요청으로 네이버 콘솔의 lunchMenuRecommend 애플리케이션을 직접 확인.
  Dynamic Map 활성화와 GitHub Pages 허용 URL 등록을 확인하고 웹용 Client ID만 연결.
  Client Secret은 저장소/사이트에 사용하지 않음.
- SDK 3.10.5가 namespace export 전에 callback을 실행하여 window.naver가 없는 오류를 재현.
  callback에서 queueMicrotask로 SDK 실행 종료 뒤 초기화하도록 수정하고 초기화 예외 로그 추가.
- 배포 버전 dcb693c: 실제 네이버 타일·저작권·로고·반경·마커 표시 확인.
- 390px 브라우저에서 반경 300m 결과 4개, 사각형 초기 결과 2개,
  북동쪽 꼭짓점 드래그 후 4개로 변경 확인.
- 지도 마커 클릭 → 메뉴 상세 → 닫기, 반경 복귀, 이 위치에서 찾기 확인.
  인증 오류 안내는 숨겨진 상태 유지. 배포 URL의 콘솔 오류 없음.
- 실제 iPhone/Android 실기기, GPS 권한 및 Google 로그인/리뷰/실제 식당 데이터는 이전과 같이 미검증 또는 미구현.

## 게스트 설정 쿠키 (2026-11-03)

- 30일 쿠키에 검색 반경, 지역/영역, 카테고리, 예산, 검색어, 정렬, 예시 표시 저장. 즐겨찾기는 기존 localStorage 유지.
- 위치 권한 자동 요청 없음. 이전 좌표는 현재 위치로 오인하지 않도록 지난번 선택 위치로 표시.
- 버전 및 값 검증, 손상/차단 쿠키 처리, 검색어 길이 제한, HTTPS Secure / SameSite=Lax / 프로젝트 경로 적용.
- 게스트 설정 초기화와 저장 안내 추가. 로그인은 아직 미구현이므로 현재 게스트 화면에만 적용.
- 네이버 실제 장소 검색은 별도 검색 API 인증과 서버 중계가 필요한 후속 작업. 사용자는 네이버 검색만 사용하도록 지정.
- 검증: npm test 8개 통과, node --check 통과. 로컬 새로고침 후 300m/한식/제육/가격순 복원 확인.
- 배포 e3c7038: 실제 지도에서 영역 모드 새로고침 복원, 예산 1만원 이하 복원, 게스트 초기화 확인. 모바일 390px 안내 캡처. 실제 모바일 기기 검증은 미수행.
- 네이버 개발자센터 접속은 로그인 화면에서 중단. 사용자 로그인과 검색 API 신규 등록, 서버 설정 필요.

## 지도 확대·축소 컨트롤 제거 (2026-11-03)

- 사용자 요청으로 zoomControl을 false로 변경하고 슬라이더 위치 옵션 제거.
- 기존 지도 제스처 설정은 유지. 실제 모바일 핀치 제스처는 실기기 미검증.
- node --check app.js 통과.

## 선택 영역 전체 이동 (2026-11-03)

- 사각형 내부에 SDK 드래그 마커를 배치해 영역 전체 이동. 꼭짓점은 위에 표시하여 크기 조절 유지.
- 이동 중 지도 드래그를 일시 중지하고 종료/모드 해제 시 복원. 놓으면 검색 결과와 쿠키 갱신.
- 줌 변경과 크기 조절 시 이동 영역 크기 재계산. 실기기 터치/핀치 검증은 미수행.
