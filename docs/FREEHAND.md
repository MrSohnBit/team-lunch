# 자유형 검색 영역 (2026-11-03)

- 자유형 선택 / 영역 추가 후 지도에서 경계를 그려 선택. 손을 놓으면 닫힌 영역이 됨.
- 최대 5개, 내부 드래그 이동, 개별 삭제, 취소 버튼 및 Escape 지원.
- 그리기·도형 이동 중 지도 드래그 차단, 완료·취소 시 기존 설정 복원.
- 오목한 도형 및 경계 포함 판정, 여러 영역 합집합 필터. 기존 사각형 쿠키는 꼭짓점 4개로 이관.
- 도형당 최대 32개 점으로 단순화, 좌표 소수점 5자리 및 압축 문자열로 30일 쿠키 저장.
- 검증: node 테스트 13개 통과. 그리기/이동/취소 이벤트, 오목한 영역 판정, 최대 5개 도형과 100자 검색어 쿠키 4KB 미만 확인.
- 로컬 390px 브라우저에서 지도 로드·그리기 진입·안내 및 취소 버튼 표시 확인. 실제 휴대폰 손가락 그리기/핀치 및 브라우저 연속 곡선 입력은 미검증.

## 명시적 저장 (2026-11-03)

- 영역 그리기·이동·삭제는 임시 변경으로 미리보기. 저장하기를 눌러야 쿠키에 반영.
- 변경 취소는 마지막 저장 영역으로 복귀하며 그리기도 종료. 마지막 영역 삭제 후에도 저장/취소 제공.
- 필터를 바꿔도 미저장 영역이 쿠키에 섞이지 않도록 저장 데이터 분리. 저장 실패 시 성공 안내 대신 오류 표시.
- 반경/현재 위치 등 검색 모드 전환은 기존처럼 영역 선택 해제.
- 테스트: 영역 복원·그리기 중 취소 포함 13개 통과.
